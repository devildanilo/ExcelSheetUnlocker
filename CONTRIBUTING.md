# Contributing to Excel Sheet Unlocker

Thank you for your interest in contributing! Here's how to get started.

## How to Contribute

1. **Fork** the repository
2. Create a **branch** for your change (`git checkout -b feature/my-improvement`)
3. Make your changes and test them
4. Open a **Pull Request** with a clear description of what you changed and why

All PRs are reviewed by the maintainer before merging. Low-quality or out-of-scope changes may be declined — please open an **Issue** first to discuss larger ideas before investing time coding them.

## Reporting Bugs / Suggesting Features

Open a [GitHub Issue](../../issues) with:
- A clear title
- Steps to reproduce (for bugs)
- Your OS and Python version (for bugs)
